# 🍉 Watermelon on the Run

**[▶ Play in browser](https://hazekerr.github.io/watermelon-on-the-run/)**

3D browser runner: a watermelon escapes the Astrakhan market with a knife-wielding vendor on its tail.

- five zones: market, embankment, old town, port, bridge
- bosses, eight story endings and a map of endings
- modes: story, endless, rhythm, 60-second market heist, Volga boat
- weather, day and night, skill tree, costumes, achievements

Controls: keyboard (arrows / WASD). The game text is in Russian.

Built as a single HTML file on [Three.js](https://threejs.org/).
